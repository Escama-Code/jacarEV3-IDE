# Páginas

| Arquivo | Função |
|---------|--------|
| `index.html` | Menu principal |
| `public/campanha.html` | **Só escolha** de módulo e missão |
| `public/missao.html?id=...` | **IDE** da missão (dicas, avaliação, estrelas) |
| `public/sandbox.html` | IDE livre |

Fluxo: Menu → Campanha → escolhe missão → `missao.html?id=cb01-led` → programa → volta em "Missões".
